## Инструменты настройки сети

Если ваша система имеет поддерживаемое оборудование, Ethernet или Wi-Fi сетевой адаптер должен быть автоматически обнаружен, загружен драйвер и предпринята попытка автоматической конфигурации через DHCP.

SystemRescue использует NetworkManager как основной инструмент настройки сети. Он предоставляет очень удобный графический интерфейс для конфигурации сети. Это упрощает настройку особенно для беспроводных сетей. Например, беспроводные сети будут автоматически обнаружены и подключение к ним очень простое. Внутри X11 NetworkManager доступен как небольшая иконка в панели задач прямо рядом с часами. Также он предоставляет `nmcli` и `nmtui`, если хотите конфигурировать сеть через командную строку или полуграфический интерфейс из терминала.

Также можно настроить сеть с помощью других инструментов, таких как стандартные команды `ifconfig` или `ip`. В этом случае нужно сначала остановить службу NetworkManager, иначе возникнет конфликт и вы потеряете настройки. Остановить её можно, запустив `systemctl stop NetworkManager` в оболочке.

## Ручная настройка сети

По умолчанию все сетевые интерфейсы активны и автоматически конфигурируются. Команда `nmcli` покажет обзор того, что сейчас настроено.

Для отключения и повторного включения интерфейсов используйте `nmcli conn down "Wired connection 1"` и `nmcli conn up "Wired connection 1"`. Обратите внимание, что "Wired connection 1", используемый здесь как пример, не является именем интерфейса, присвоенным ядром, а внутренним именем NetworkManager. Используйте `nmcli` для получения обзора всех подключений и их имён.

Для ручного установления статического IP, маски сети, шлюза также можно использовать nmcli:

```
nmcli conn mod "Wired connection 1" ipv4.method manual
nmcli conn mod "Wired connection 1" ipv4.addr 192.168.1.20/24
nmcli conn mod "Wired connection 1" ipv4.gateway 192.168.1.1
nmcli conn mod "Wired connection 1" ipv4.dns 192.168.1.1
nmcli conn up "Wired connection 1"
```

Последний "conn up" требуется для повторной конфигурации интерфейса с новыми параметрами.

Для возврата к автоматической конфигурации через DHCP используйте:

```
nmcli conn mod "Wired connection 1" ipv4.method auto
nmcli conn up "Wired connection 1"
```

## Брандмауэр

Начиная с версии 6.0.4 SystemRescue поставляется с включённым брандмауэром iptables для блокировки входящих запросов подключений по умолчанию. Нужно обновить конфигурацию iptables или остановить службы iptables и ip6tables, если нужно получать входящие подключения извне. Можно загрузиться с SystemRescue через опцию `nofirewall` в командной строке, если не хотите брандмауэр.

## Запуск SSH-сервера

SSH позволяет использовать оболочку на другом компьютере и копировать файлы (с помощью scp или rsync через ssh). SSHd уже запущен в фоновом режиме. Но для разрешения входящих подключений нужно разрешить подключение через брандмауэр (см. выше) и изменить пароль root. Просто введите `passwd` для установки пароля. Также можно использовать опции загрузки `rootpass=xxx` или `rootcryptpass=xxxx` перед запуском SystemRescue для определения пароля root.

Более безопасная альтернатива — использование файлов SSH-ключей. Можно установить авторизованные ключи на вашу среду SystemRescue с [YAML-файлом](/manual/Configuring_SystemRescue_sysconfig/).

## Доступ к разделу на компьютере Windows через CIFS

SystemRescue поставляется с пакетом клиента smbfs/cifs, который позволяет подключаться к Windows-машине с общими дисками. В новых ядрах поддержка smbfs была заменена cifs, поэтому следует не использовать smbfs.

Пакет mount-cifs позволяет получить доступ к компьютеру Windows в сети.
