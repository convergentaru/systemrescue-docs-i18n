## Обзор

SystemRescue поставляется с опциями, которые позволяют пользователям изменить способ его работы. Например, есть опции для управления используемой раскладкой клавиатуры, нужно ли запускать систему из памяти или с загрузочного устройства, запускать ли автоматически графическую среду и т.д. Можно перейти по ссылке, чтобы увидеть список [опций загрузки](/manual/Booting_SystemRescue/), поддерживаемых в командной строке.

Эти опции устанавливаются в командной строке загрузки. Чтобы изменить их, можно либо вручную отредактировать командную строку загрузки из загрузчика во время работы, либо сделать изменения постоянными, отредактировав конфигурационные файлы загрузчиков, которые это isolinux при запуске в BIOS-режиме или Grub при запуске в UEFI-режиме.

## Особенности конфигурации

Начиная с SystemRescue версии 9.00 есть ещё один способ конфигурирования SystemRescue. Теперь можно редактировать YAML-файлы на загрузочном устройстве для его настройки. Этот способ конфигурации был введён, чтобы сделать постоянные конфигурационные изменения простыми, и эти опции эффективны как для BIOS-режима, так и для UEFI-режима.

Конфигурационные YAML-файлы SystemRescue находятся в папке `sysrescue.d`, расположенной на загрузочном устройстве.

SystemRescue поставляется с файлом YAML конфигурации по умолчанию, поэтому он предоставляет хороший пример такого файла, который можно использовать как отправную точку. Можно редактировать его для замены опций своими предпочтениями.

## Области (Scopes)

Эти файлы yaml-конфигурации поддерживают несколько областей. Основная область называется `global` и содержит общие конфигурационные записи. Почти все записи в области global имеют опции командной строки загрузки того же имени и документированы в [Boot options](/manual/Booting_SystemRescue/).

Область `autorun` используется для определения конфигурационных записей, которые используются [autorun](/manual/Run_your_own_scripts_with_autorun/) и документированы там.

Область `gui_autostart` используется для определения конфигурационных записей, которые используются [gui_autostart](/manual/gui_autostart_Start_programs_on_graphical_desktop/) и документированы там.

Область `autoterminal` используется для определения конфигурационных записей, которые используются [autoterminal](/manual/autoterminal_scripts_on_virtual_terminal/) и документированы там.

Область `sysconfig` используется для определения определённых аспектов конфигурации системы.
