# Скачивание и запись (burning)

## Скачивание

SystemRescue предоставляется в виде ISO образа который нужно записать на CD/DVD диск и создаст загрузочный носитель. SystemRescue не может быть запущен как часть вашего оригинального операционной системы.

Вы можете скачать ISO образ файл с вашим любимым браузером. Если у вас проблемы скачайте файл используя [wget](https://www.gnu.org/software/wget/) который часто установлен по умолчанию под Linux, или получите [windows версию wget](http://gnuwin32.sourceforge.net/packages/wget.htm). Скачивание с помощью wget простое. Вам нужно просто запустить следующую команду в терминале (cmd.exe на windows)

```
wget -c address-of-the-iso-file
```

Как только файл скачан проверьте что не было ошибки сравнив checksum совпадает ли с тем который показан на странице загрузки. Вы можете запустить sha256sum на iso файле чтобы получить checksum вашей локальной копии и убедиться что файл не был повреждён.

## Запись (Burning)

Вы можете записать ISO образ файл с большинством софта для записи. Под Windows вы можете нажать правой кнопкой мыши на ISO образ в explorer чтобы найти контекстное меню которое предлагает записать ISO образ на DVD writer.

Под Linux вы можете использовать графические программы такие как k3b, xfburn, brasero или командные строки программы такие как wodim или xorriso.

Запись с помощью wodim простая. Сначала наберите `wodim --devices` чтобы получить идентификатор вашего устройства. Затем наберите следующее чтобы фактически записать iso образ:

```
wodim dev=/dev/scXX -v systemrescue-x.y.z.iso
```

Например:

```
wodim dev=/dev/sr0 speed=8 -v systemrescue-x.y.z.iso
```
