## Скачивание

SystemRescue распространяется в виде ISO-образа, который нужно записать на CD/DVD для создания загрузочного носителя. SystemRescue не может выполняться как часть вашей установленной операционной системы.

Вы можете скачать ISO-образ с помощью любого браузера. Если возникнут проблемы, используйте [wget](https://www.gnu.org/software/wget/), который часто устанавливается по умолчанию в Linux, или скачайте [версию wget для Windows](http://gnuwin32.sourceforge.net/packages/wget.htm). Скачивание через wget очень просто — нужно выполнить следующую команду в терминале (cmd.exe на Windows):

```
wget -c адрес-файла-iso
```

После скачивания файла проверьте, что он не повреждён, сравнив контрольную сумму с той, что указана на странице загрузки. Выполните `sha256sum` на ISO-файле, чтобы получить хеш вашей копии и убедиться в её целостности.

## Запись образа

ISO-образ можно записать большинством программ для записи дисков. В Windows вы можете правой кнопкой мыши нажать на ISO-файл в проводнике и выбрать контекстное меню для записи образа на DVD-привод.

В Linux используйте графические программы: K3b, Xfburn, Brasero, или командные строки: wodim, xorriso.

Запись через wodim проста. Сначала выполните ```wodim --devices```, чтобы получить идентификатор вашего устройства записи. Затем выполните следующую команду для записи ISO-образа:

```
wodim dev=/dev/scXX -v systemrescue-x.y.z.iso
```

Например:

```
wodim dev=/dev/sr0 speed=8 -v systemrescue-x.y.z.iso
```
