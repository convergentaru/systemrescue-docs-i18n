# Обзор SystemRescue

## Описание

SystemRescue — это Linux система, доступная на загрузочном CD-ROM, которая позволяет вам восстановить вашу систему и ваши данные после краха. Она также стремится предоставить простой способ выполнения административных задач на вашем компьютере, таких как создание и редактирование разделов жёсткого диска. Она содержит много системных утилит (parted, fsarchiver, инструменты файловых систем, ...) и базовых (редакторы, midnight commander, сетевые инструменты). Она стремится быть очень простой в использовании: просто загрузитесь с носителя загрузки, и вы сможете делать всё. Ядро системы поддерживает большинство важных файловых систем (ext3, ext4, xfs, btrfs, reiserfs, vfat, ntfs, iso9660), и сетевые (samba и nfs).

Вы можете использовать SystemRescue для многих задач:

* В первый раз когда вы используете компьютер, когда нет установленной операционной системы. Первая задача — создание разделов на жёстком диске, и установка операционной системы. С этим CD-ROM вы можете легко создавать разделы с графическим инструментом разбиения GParted, и вы можете установить Gentoo Linux.
* После краха, или ошибки, у вас могут быть проблемы с загрузкой. Например, после установки Windows ваш загрузчик (LILO, Grub) мог быть стёрт из MBR. С этим CD-ROM у вас есть всё необходимое для переустановки Grub или Lilo.
* Для пользователей Windows которые не имеют Linux установленный, он предоставляет маленький Linux System с большинством важных системных инструментов. Например, пользователи Windows могут делать резервные копии их Windows системного раздела используя Linux инструменты.

## Содержание

Вот краткий список который описывает что вы найдёте на этой rescue системе:

* Недавнее Linux ядро, которое поддерживает большинство важных файловых систем, и самое важное железо. Поддерживаемые файловые системы включают: ext3, ext4, xfs, reiserfs, fat16, fat32, jfs, ntfs. Ядро поддерживает NFS и Samba.
* Графические инструменты разбиения, которые стремятся быть free partition-magic клонами для Linux. Вы можете использовать GParted.
* Самые важные консольные системные инструменты для Linux. Конечно, у вас есть GNU Parted (partition editor), Partimage или FSArchiver (drive image clone) для резервного копирования разделов в image файл, File system tools (e2fsprogs для ext4, xfsprogs, reiserfsprogs для reiserFS, jfsutils, dosfstools для FAT, ntfsprogs для NTFS. Вы можете использовать dump/restore для резервного копирования ext4 раздела).
* ntfs-3g (третье поколение драйвера NTFS) предоставляет полную read-write поддержку NTFS разделов от Linux.
* Обычные инструменты для пользователей Linux: tar/gzip/bzip2 для архивирования файлов. Те же инструменты для пользователей Windows: zip/unzip, p7zip предоставляются. Это означает что вы способны backup/restore ваши Windows данные. Мы добавили DAR (Disk Archiver). Это программа как tar, но более мощная
* Midnight-Commander (наберите <code>mc</code> на командной строке консоли) — это free Norton-Commander clone для Linux. С mc легко browse, copy, move, edit все файлы на вашем компьютере. Если вы не знаете хорошо все Linux shell команды, вы можете начать с mc.
* Вы можете использовать базовые web браузеры чтобы получить некоторую документацию пока вы работаете от rescue окружения.
* Конечно, редакторы важны когда у вас есть проблемы. Nano (лёгкий редактор), vim (vi improved) и qemacs (emacs clone) предоставляются для текстового режима.
* XFCE графический desktop environment позволяет вам использовать графические программы такие как GParted и графические text редакторы такие как Geany.
