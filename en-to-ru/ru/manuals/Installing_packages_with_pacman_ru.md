## Обзор pacman

Pacman — это менеджер пакетов Arch Linux и его производных, включая SystemRescue. Он управляет установкой, обновлением и удалением пакетов из официальных репозиториев Arch Linux.

SystemRescue использует официальные репозитории Arch Linux для установки пакетов.

## Основные команды pacman

### Обновление базы данных репозиториев

Перед установкой или обновлением пакетов всегда обновляйте базу данных:
```bash
pacman -Sy
```

Для обновления базы данных и всех установленных пакетов одновременно:
```bash
pacman -Syu
```

Параметры:
* `-S` — синтаксис установки пакетов
* `-y` — обновление базы данных репозиториев
* `-u` — обновить уже установленные пакеты

### Установка пакетов

Установите один или несколько пакетов:
```bash
pacman -S пакет-имя
pacman -S пакет-1 пакет-2 пакет-3
```

Параметры:
* `-S` — синтаксис установки пакетов
* `-i` — интерактивный режим (позволяет выбрать компоненты)

### Обновление пакета

Обновите конкретный пакет:
```bash
pacman -Syu пакет-имя
```

Обновите все установленные пакеты:
```bash
pacman -Syu
```

Параметры:
* `-S` — синтаксис установки пакетов
* `-y` — обновление базы данных репозиториев
* `-u` — обновить уже установленные пакеты

### Удаление пакетов

Удалите установленный пакет:
```bash
pacman -Rsn пакет-имя
```

Параметры:
* `-R` — синтаксис удаления пакетов
* `-s` — удалить зависимости пакета, которые больше не используются другими пакетами
* `-n` — не требовать подтверждения при удалении

## Поиск пакетов

### Поиск в репозиториях

Поиск пакетов по названию:
```bash
pacman -Ss название-пакета
```

Пример поиска web-браузера:
```bash
pacman -Ss firefox
```

### Просмотр информации о пакете

Получите подробную информацию о конкретном пакете:
```bash
pacman -Si пакет-имя
```

Это покажет:
* Описание пакета
* Версию пакета
* Репозиторий
* Зависимости (required, optional, conflicts)
* Размер пакета

### Просмотр информации о системе

Список всех установленных пакетов:
```bash
pacman -Q
```

Узнать информацию об установленном пакете:
```bash
pacman -Qi пакет-имя
```

## Работа с зависимостями

### Автоматическая установка зависимостей

Pacman автоматически устанавливает зависимости при установке пакета:
```bash
pacman -S firefox
# Автоматически установит required и optional зависимости
```

### Установка только необходимых зависимостей

Установите пакет без опциональных зависимостей:
```bash
pacman -S --needed firefox
```

### Просмотр недостающих зависимостей

Смотрите какие зависимости ещё нужно установить:
```bash
pacman -Si пакет | grep "Depends on:"
```

### Удаление orphaned пакетов

Удалите пакеты которые больше не нужны (не используются другими пакетами):
```bash
pacman -Rns $(pacman -Qdtq)
```

Параметры:
* `-R` — синтаксис удаления пакетов
* `-n` — не требовать подтверждения
* `-s` — удалить зависимости пакета которые больше не используются

## Репозитории Arch Linux

### Список репозиториев

Список доступных репозиториев:
```bash
pacman -Sl archlinux | head -20
```

Основные репозитории:
* **core** — базовые компоненты системы
* **extra** — дополнительные пакеты для повседневного использования
* **community** — пакеты от сообщества

### Указание конкретного репозитория

Установите пакет из конкретного репозитория:
```bash
pacman -S community/paket-name
```

## Конфигурация pacman

### Файл конфигурации

Основной файл конфигурации `/etc/pacman.conf`:
```ini
[options]
# База данных и кэш
DBPath           = /var/lib/pacman
CacheDir         = /var/cache/pacman/pkg
GPGDir           = /etc/pacman.d/gnupg
HookDir          = /usr/lib/pacman/hooks

# Проверка подписей GPG
SigLevel = Required
LocalFileSigLevel = Optional

# Сжатие пакетов
ParallelDownloads = 5
```

### Редактирование конфигурации

Отредактируйте файл конфигурации:
```bash
nano /etc/pacman.conf
```

## Безопасность pacman

### Инициализация ключей GPG

Инициализируйте и импортируйте ключи GPG:
```bash
pacman-key --init
pacman-key --populate archlinux
```

Это установит официальные ключи подписи репозиториев Arch Linux.

### Проверка целостности пакетов

Pacman автоматически проверяет целостность пакетов при установке.

## Частые сценарии использования

### Установка базовых инструментов

Установите базовые инструменты разработки:
```bash
pacman -S base-devel git make gcc
```

### Установка графической среды

Установите X.Org и терминал:
```bash
pacman -S xorg-server xterm dbus
```

### Установка инструментов системного администрирования

Пакеты для работы с дисками и сетью:
```bash
pacman -S gparted parted fdisk \
           networkmanager netctl dhcpcd \
           wget curl rsync ssh openssh-server
```

### Установка утилит для файловой системы NTFS

Для работы с Windows-дисками:
```bash
pacman -S ntfs-3g exfatprogs dosfstools
```

## Решение проблем

### Ошибка: database error

Если база данных повреждена, переустановите её:
```bash
pacman -Rns pacman
pacman -S pacman
```

### Ошибка: GPG signature verification failed

Проверьте ключи GPG:
```bash
pacman-key --list-keys | grep archlinux
```

Обновите ключи:
```bash
pacman-key --refresh-keys
```

### Недостаточно места на диске

Очистите кэш пакетов:
```bash
pacman -Sc
```

Или удалите старые пакеты:
```bash
rm /var/cache/pacman/pkg/*.pkg.tar.zst
```

## Заключение

Pacman — мощный и простой менеджер пакетов для SystemRescue. Используйте его для установки, обновления и удаления пакетов из официальных репозиториев Arch Linux. Всегда обновляйте базу данных перед операциями с пакетами и проверяйте подписи GPG для безопасности.
