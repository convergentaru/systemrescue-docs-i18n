# Загрузка сломанной Linux системы

Иногда у нас могут быть проблемы с загрузкой Linux системы которая установлена на диске. Например, после некоторых административных задач или после установки операционной системы на ваш жёсткий диск вы можете потерять возможность загрузки Linux потому что **другая система могла перезаписать MBR или заменить загрузчик**. В таких случаях полезно использовать SystemRescue чтобы запустить существующую Linux систему которая уже установлена на диске. И как только эта система запущена вы сможете [поправить загрузчик](/disk-partitioning/Repairing-a-damaged-Grub/).

Начиная с SystemRescue версии 6.1.4 он поддерживает параметр `findroot` на командной строке загрузки. Вы можете использовать его либо набрав этот параметр на командной строке загрузки, либо выбрав **Boot from a Linux operating system installed on the disk** в предопределённом SystemRescue меню загрузки. Когда вы запускаете SystemRescue с этой опцией включённой он попытается найти и запустить любую Linux операционную систему которая установлена на диске. Это поддерживает Linux операционные системы установленные на обычных файловых системах включая LVM диск и dm-crypt зашифрованный диск. Если найдено несколько систем он покажет меню чтобы вы могли выбрать какую из них хотите запустить.

Как только вам удалось запустить вашу Linux операционную систему вы сможете использовать различные команды для исправления системы. Это включает команды для переустановки загрузчика на диске, для обновления или замены пакетов, или для обновления конфигурационных файлов.
