## Обзор AUR

AUR (Arch User Repository) — это сообщество-репозиторий пользовательских пакетов для Arch Linux и его производных, включая SystemRescue. Pакеты в AUR создаются пользователями и не проходят официальную проверку Arch Linux Foundation.

SystemRescue предоставляет доступ к AUR через утилиты `yay`, `paru` или другой AUR-клиент.

## Предварительные требования

### Установка AUR-клиента

Сначала нужно установить AUR-клиент. Popular варианты:
* **yay** — быстрый, с поддержкой графического интерфейса
* **paru** — альтернатива yay с улучшенной документацией
* **aurman** — ещё один популярный клиент

Установите `yay`:
```bash
pacman -Syu base-devel
git clone https://aur.archlinux.org/yay.git
cd yay
makepkg -si
cd ..
rm -rf yay
```

Или установите через pacman напрямую:
```bash
pacman -S --needed git base-devel
git clone https://aur.archlinux.org/yay.git
cd yay && makepkg -si && cd .. && rm -rf yay
```

### Настройка ключей GPG

Для безопасности установите и импортируйте ключи GPG:
```bash
pacman-key --init
pacman-key --populate archlinux
```

## Поиск пакетов в AUR

### Использование yay для поиска

Поиск пакетов по названию:
```bash
yay -Ss название-пакета
```

Поиск с фильтрами:
```bash
# Поиск только установленных пакетов
yay -Qs название

# Поиск только доступных обновлений
yay -Qu | grep название

# Поиск по описанию
yay -Ss "описание пакета"
```

### Просмотр информации о пакете

Посмотрите информацию о конкретном пакете:
```bash
yay -Si пакет-имя
```

Это покажет:
* Описание пакета
* Зависимости (required и optional)
* Размер пакета после установки
* Автор пакета
* Последнюю дату обновления

## Установка пакетов из AUR

### Простая установка

Установите пакет напрямую из AUR:
```bash
yay -S пакет-имя
```

### Установка с подтверждением

При установке yay предложит подтвердить установку. Введите `y` для подтверждения:
```bash
yay -S packet-name
# Yay спросит: "Proceed with installation? [Y/n]"
# Введите: y
```

### Установка нескольких пакетов

Установите несколько пакетов одновременно:
```bash
yay -S пакет-1 пакет-2 пакет-3
```

## Обновление пакетов из AUR

### Обновление установленных AUR-пакетов

Обновите только пакеты из AUR:
```bash
yay -Syu --auronly
```

### Обновление всей системы вместе с AUR

Полное обновление системы и AUR-пакетов:
```bash
yay -Syu
```

## Управление зависимостями

### Установка пакетов с зависимостями

AUR-клиент автоматически устанавливает зависимости:
```bash
yay -S пакет-с-зависимостями
```

### Просмотр недостающих зависимостей

Смотрите какие зависимости ещё нужно установить:
```bash
yay -Si пакет | grep "Optional Deps:"
```

## Работа с удалёнными пакетами

### Удаление AUR-пакета

Удалите установленный AUR-пакет:
```bash
yay -Rsn пакет-имя
```

Параметры:
* `-R` — удалить пакет
* `-s` — очистить зависимости
* `-n` — не требовать подтверждения

### Чистка orphaned пакетов

Удалите пакеты, которые больше не нужны (не используются другими пакетами):
```bash
yay -C
```

## Использование AUR-рецептов

AUR-рецепты — это PKGBUILD файлы для создания пакетов. Вы можете:

### Редактирование рецепта

Скопируйте и отредактируйте рецепт:
```bash
cd /tmp
git clone https://aur.archlinux.org/пакет.git
cd пакет
nano PKGBUILD
```

Измените зависимости, скрипты установки или другие параметры.

### Создание кастомного пакета

Создайте свой собственный AUR-пакет:
```bash
# Создайте новый репозиторий
mkdir -p ~/aur-packages/packet-name
cd ~/aur-packages/packet-name

# Создайте PKGBUILD
cat > PKGBUILD << 'EOF'
pkgname=your-package
pkgver=1.0
pkgrel=1
arch=(any)
license=('MIT')
url='https://example.com'
depends=(dependency1 dependency2)

build() {
    # Компиляция пакета
}

package() {
    # Установка файлов в пакет
}
EOF

# Соберите и установите пакет
makepkg -si
```

## Безопасность AUR

### Проверка подписей GPG

Проверяйте пакеты с помощью GPG:
```bash
yay -S --sigverify пакет-имя
```

### Проверка отзывов сообщества

Перед установкой проверьте отзывы в wiki пакета:
```bash
yay -Si пакет | grep -A 20 "Wiki URL"
```

Откройте ссылку и проверьте:
* Активность разработчика
* Отзывы пользователей
* Известные проблемы

### Избежание опасных пакетов

Не устанавливайте пакеты которые:
* Не имеют отзывов в wiki
* Были обновлены недавно без истории изменений
* Имеют плохие отзывы сообщества

## Настройка yay

### Редактирование конфигурации yay

Отредактируйте файл конфигурации:
```bash
nano ~/.config/yay/config.json
```

Основные настройки:
```json
{
    "GPGFetch": 1,
    "AnsibleConfirm": false,
    "MakepkgExternalEditor": "nano",
    "SudoWrapper": false,
    "ColorScheme": "default"
}
```

### Настройка сжатия

Измените алгоритм сжатия для пакетов:
```bash
yay -C
# Затем отредактируйте ~/.cache/yay/config.json
```

## Частые операции

### Полный цикл: поиск, установка, обновление

```bash
# Поиск и установка
yay -Ss paket-name
yay -S packet-name

# Обновление пакета
yay -Su пакет-имя

# Обновление всех AUR-пакетов
yay -Syu --auronly

# Чистка orphaned пакетов
yay -C
```

### Удаление с очисткой зависимостей

```bash
# Удалить пакет и его зависимости
yay -Rsn пакет-имя

# Полная очистка (орфанённые пакеты + кэш)
yay -Cs
```

## Решение проблем

### Ошибка: missing dependencies

Если pacman говорит о недостающих зависимостях:
```bash
yay -S --depends-on-all пакет-имя
```

### Ошибка: GPG signature verification failed

Проверьте ключи GPG:
```bash
pacman-key --list-keys | grep archlinux
```

Установите ключи Arch Linux:
```bash
pacman-key --populate archlinux
```

### Пакет не устанавливается

Попробуйте переустановить пакет с очисткой кэша:
```bash
yay -Sc
yay -S пакет-имя
```

## Заключение

AUR предоставляет доступ к тысячам пользовательских пакетов для SystemRescue. Используйте yay или другой AUR-клиент для установки, обновления и управления пакетами. Всегда проверяйте пакеты из AUR перед установкой — они не проходят официальную проверку Arch Linux Foundation.
