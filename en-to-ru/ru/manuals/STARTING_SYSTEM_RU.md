# Начало использования системы

Когда вы начинаете, вы должны прочитать сообщения которые дают вам самую важную информацию о том как использовать эту систему. Вы должны прочитать текст.

Вы можете войти на другой консоль. Пароль root пустой. Введите <code>dhcpcd eth0</code> (или similar) для auto-конфигурации network используя DHCP.

Для запуска ssh сервера на этой системе, введите <code>systemctl start sshd</code>. Если вам нужно войти remotely как root, введите <code>passwd root</code> для reset пароля пользователя root к известному значению.

Если вам нужны графические инструменты (такие как GParted) вы должны пойти в graphical окружение. Вы должны просто ввести <code>startx</code> для запуска его.

Вам может понадобиться использовать редактор. Доступные редакторы: vim, nano в console режиме. Вы также можете использовать featherpad и geany в graphical окружении.
