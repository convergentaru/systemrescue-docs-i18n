При запуске нужно прочитать сообщения, которые дают самую важную информацию об использовании этой системы. Нужно прочитать текст.

Можно войти в другую консоль. Пароль root пустой. Введите
<code>dhcpcd eth0</code> (или аналогичное) для автоматической конфигурации сети через DHCP.

Для запуска ssh-сервера на этой системе введите <code>systemctl start sshd</code>.
Если нужно войти удалённо как root, введите <code>passwd root</code>, чтобы сбросить
пароль пользователя root до известного значения.

Если нужны графические инструменты (например, GParted), нужно перейти в графическую среду. Нужно просто ввести <code>startx</code> для её запуска.

Возможно потребуется использовать редактор. Доступные редакторы: vim, nano в консольном режиме. Также можно использовать featherpad и geany в графической среде.
