## Введение

NTFS (New Technology File System) — это файловая система по умолчанию в последних версиях Windows, и системный диск Windows основан на формате NTFS.

Linux предлагал полную поддержку чтения для NTFS-файловых систем уже давно. Однако до недавнего времени отсутствовала поддержка записи NTFS, идущая вместе с ядром. Для доступа к полной поддержке чтения/записи NTFS-дисков нужно было использовать [ntfs-3g](https://wiki.archlinux.org/title/NTFS-3G), которое является пользовательским приложением и поэтому работает очень медленно.

SystemRescue версии 9.00 поставляется с Linux-5.15, который приносит
[драйвер файловой системы ntfs3 на основе ядра](https://www.kernel.org/doc/html/latest/filesystems/ntfs3.html). Этот современный модуль ядра обеспечивает полную поддержку чтения и записи NTFS в Linux. Это рекомендуемый способ доступа к NTFS-дискам из SystemRescue. На данный момент ntfs-3g всё ещё является драйвером NTFS по умолчанию, поэтому нужно явно указать, что вы хотите использовать ntfs3, чтобы воспользоваться этим новым драйвером.

Если не знаете имя устройства, содержащего NTFS-файловую систему, используйте `lsblk` и `blkid` или GParted для идентификации диска. В следующих примерах будем считать, что имя устройства `/dev/xxx`, пожалуйста, замените это на имя фактического устройства.

## Полная поддержка чтения/записи

Если нужна полная поддержка записи NTFS, используйте команду монтирования типа:

```
mkdir -p /mnt/windows
mount -t ntfs3 /dev/xxx /mnt/windows
```

## Только чтение

Если нужно только чтение для NTFS-дисков, можно указать опцию `-o ro`
для ограничения доступа к файловой системе). Эта поддержка только чтения безопаснее (нельзя изменить или повредить данные) и может использоваться, например, если нужно просто сделать резервную копию нескольких файлов или прочитать документ.

```
mkdir -p /mnt/windows
mount -t ntfs3 -o ro /dev/xxx /mnt/windows
```
