## Описание

SystemRescue — это Linux-система, доступная на загрузочном CD-ROM, которая позволяет вам восстановить систему и ваши данные после сбоя. Она также предоставляет простой способ выполнения административных задач на вашем компьютере, таких как создание и редактирование разделов жёсткого диска. Система содержит множество утилит (parted, fsarchiver, инструменты управления файловыми системами) и базовых программ (редакторы текста, Midnight Commander, сетевые инструменты). SystemRescue стремится быть максимально простой в использовании: просто загрузитесь с носителя и начните работать. Ядро системы поддерживает большинство важных типов файловых систем (ext3, ext4, xfs, btrfs, reiserfs, vfat, ntfs, iso9660) и сетевые протоколы (Samba и NFS).

Вы можете использовать SystemRescue для следующих задач:

* При первом использовании компьютера, когда операционная система ещё не установлена. Первая задача — создание разделов на жёстком диске и установка новой ОС. С этим CD-ROM вы легко создаёте разделы с помощью графического инструмента GParted и можете установить Gentoo Linux.
* После сбоя или ошибки у вас могут возникнуть проблемы с загрузкой. Например, после установки Windows ваш загрузчик (LILO, GRUB) мог быть удалён из MBR. С этим CD-ROM у вас есть всё необходимое для переустановки GRUB или LILO.
* Для пользователей Windows, у которых не установлен Linux, SystemRescue предоставляет небольшую Linux-систему с важными системными инструментами. Например, пользователи Windows могут создать резервную копию своего раздела с Windows, используя Linux-инструменты.

## Содержание

Вот краткий список того, что вы найдёте на этой системе спасения:

* Актуальное ядро Linux, поддерживающее большинство важных файловых систем и оборудование. Поддерживаемые типы файловых систем: ext3, ext4, xfs, reiserfs, fat16, fat32, jfs, ntfs. Ядро поддерживает сетевые протоколы NFS и Samba.
* Графические инструменты управления разделами — бесплатные аналоги Partition Magic для Linux. Вы можете использовать GParted.
* Основные консольные системные утилиты для Linux. У вас есть GNU Parted (редактор разделов), Partimage или FSArchiver (клон образа диска) для создания резервных копий разделов в файл образа, а также инструменты управления файловыми системами: e2fsprogs для ext4, xfsprogs для XFS, reiserfsprogs для ReiserFS, jfsutils для JFS, dosfstools для FAT и ntfsprogs для NTFS. Вы можете использовать утилиты dump/restore для создания резервной копии раздела ext4.
* ntfs-3g (третье поколение драйвера NTFS) обеспечивает полную поддержку чтения и записи на NTFS-разделах из Linux.
* Стандартные инструменты для пользователей Linux: tar/gzip/bzip2 для архивации файлов. Для пользователей Windows предоставлены аналогичные инструменты: zip/unzip, p7zip. Это означает, что вы можете создавать резервные копии и восстанавливать данные Windows. Мы также добавили DAR (Disk Archiver) — программу как tar, но более функциональную.
* Midnight Commander (запустите ```mc``` в командной строке консоли) — бесплатный аналог Norton Commander для Linux. С помощью MC легко просматривать, копировать, перемещать и редактировать файлы на вашем компьютере. Если вы не знаете команды оболочки Linux, начните с MC.
* Вы можете использовать веб-браузеры для получения документации во время работы из среды спасения.
* Редакторы текста важны при возникновении проблем. Для текстового режима предоставлены: Nano (простой редактор), vim (улучшенный vi) и qemacs (клон Emacs).
* Графическая среда рабочего стола XFCE позволяет использовать графические программы, такие как GParted, а также графические текстовые редакторы, например Geany.
