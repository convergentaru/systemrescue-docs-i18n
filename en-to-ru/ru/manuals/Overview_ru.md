## Описание

SystemRescue — это Linux-система, доступная на загрузочном CD-ROM, которая позволяет вам восстановить систему и ваши данные после сбоя. Она также стремится предоставить простой способ выполнения административных задач на вашем компьютере, таких как создание и редактирование разделов жёсткого диска. Она содержит много утилит системы (parted, fsarchiver, инструменты файловой системы, ...) и базовые (редакторы, midnight commander, инструменты сети). Она стремится быть очень простой в использовании: просто загрузитесь с носителя загрузки, и вы сможете сделать всё. Ядро системы поддерживает большинство важных файловых систем (ext3, ext4, xfs, btrfs, reiserfs, vfat, ntfs, iso9660) и сетевые (samba и nfs).

Вы можете использовать SystemRescue для многих задач:

* Первый раз, когда вы используете компьютер, когда не установлена операционная система. Первая задача — создание разделов на жёстком диске и установка операционной системы. С этим CD-ROM вы можете легко создавать разделы с помощью графического инструмента разделов GParted, и вы можете установить Gentoo Linux.
* После сбоя или ошибки у вас могут возникнуть проблемы с загрузкой. Например, после установки Windows ваш загрузчик (LILO, Grub) мог быть удалён из MBR. С этим CD-ROM у вас есть всё необходимое для переустановки Grub или Lilo.
* Для пользователей Windows, у которых не установлен Linux, он предоставляет маленькую Linux-систему с большинством важных инструментов системы. Например, пользователи Windows могут создать резервную копию своего раздела системы Windows с помощью Linux-инструментов.

## Содержание

Вот краткий список, описывающий, что вы найдёте на этой системе спасения:

* Новое ядро Linux, которое поддерживает большинство важных файловых систем и самое важное оборудование. Поддерживаемые файловые системы включают: ext3, ext4, xfs, reiserfs, fat16, fat32, jfs, ntfs. Ядро поддерживает NFS и Samba.
* Графические инструменты разделов, которые стремятся быть бесплатными клонами partition-magic для Linux. Вы можете использовать GParted.
* Самые важные консольные инструменты системы для Linux. Конечно, у вас есть GNU Parted (редактор разделов), Partimage или FSArchiver (клон образа диска) для создания резервных копий разделов в файловый образ, Инструменты файловой системы (e2fsprogs для ext4, xfsprogs, reiserfsprogs для reiserFS, jfsutils, dosfstools для FAT, ntfsprogs для NTFS. Вы можете использовать dump/restore для создания резервной копии ext4 раздела.
* ntfs-3g (третье поколение драйвера NTFS) предоставляет полную поддержку чтения/записи для NTFS разделов из Linux.
* Обычные инструменты для пользователей Linux: tar/gzip/bzip2 для архивации файлов. Те же инструменты для пользователей Windows: zip/unzip, p7zip предоставляются. Это означает, что вы способны создавать резервную копию/восстанавливать ваши данные Windows. Мы добавили DAR (Disk Archiver). Это программа как tar, но более мощная
* Midnight-Commander (введите ```mc``` в командной строке консоли) — это бесплатный клон Norton-Commander для Linux. С mc легко просматривать, копировать, перемещать, редактировать все файлы на вашем компьютере. Если вы не знаете все команды Linux-оболочки, вы можете начать с mc.
* Вы можете использовать базовые веб-браузеры для получения документации, пока вы работаете из среды спасения.
* Конечно, редакторы важны, когда у вас есть проблемы. Nano (простой редактор), vim (улучшенный vi) и qemacs (клон emacs) предоставляются для текстового режима.
* Графическая среда рабочего стола XFCE позволяет использовать графические программы, такие как GParted и графические текстовые редакторы, такие как Geany.
