## Введение

В этой документации показано как сделать резервную копию данных с вашей повреждённой Windows-системы, которая не может загрузиться.

SystemRescue содержит инструменты для монтирования Windows разделов и NTFS файловой системы. Вы сможете монтировать ваш Windows раздел, копировать важные данные на USB-накопитель или в удалённое место, а затем восстановить Windows систему.

## Подготовительные работы

Убедитесь что SystemRescue загрузился с флешки или диска.

Для монтирования раздела вам понадобится:
* Доступ к командной строке SystemRescue
* USB-накопитель или другое место для хранения резервной копии
* Знание структуры разделов вашей Windows-системы

## Монтирование Windows раздела

### Определение устройства

Сначала нужно определить устройство, где находится ваш Windows раздел. Введите:
```bash
lsblk
```

Ищите разделы с файловой системой NTFS (обычно помеченной как `ntfs`).

### Монтирование с поддержкой записи

Предположим что ваш Windows раздел на устройстве `/dev/sda1`. Создайте точку монтирования:
```bash
mkdir -p /mnt/windows
mount -t ntfs3 -o defaults /dev/sda1 /mnt/windows
```

Для чтения-только режима (безопаснее):
```bash
mount -t ntfs3 -o ro /dev/sda1 /mnt/windows
```

### Проверка монтирования

Убедитесь что раздел смонтирован:
```bash
df -h /mnt/windows
```

## Копирование данных

### Копирование на USB-накопитель

Предположим что ваш USB-накопитель — `/dev/sdb1`. Скопируйте данные:
```bash
cp -a /mnt/windows/Users/* /mnt/usb-backup/
```

Или используйте rsync для более надёжного копирования:
```bash
rsync -av /mnt/windows/Users/ /mnt/usb-backup/win-users/
```

### Копирование в удалённое место

Если у вас есть доступ к сети, можно использовать rsync с SSH:
```bash
rsync -avz /mnt/windows/Users/ user@remote:/backup/windows/
```

## Работа с файлами Pagefile и Hiberfil

Windows использует файлы `pagefile.sys` (файл подкачки) и `hiberfil.sys` (файл гибернации) которые могут занимать много места. Их можно безопасно удалить:

Удалить файл подкачки:
```bash
rm /mnt/windows/pagefile.sys
```

Удалить файл гибернации:
```bash
rm /mnt/windows/hiberfil.sys
```

## Размонтирование раздела

После завершения работы обязательно размонтируйте раздел:
```bash
umount /mnt/windows
```

## Восстановление Windows

После резервного копирования данных вы можете попробовать починить вашу Windows-систему. Используйте один из следующих методов:

1. **Восстановление через аварийный диск Windows**: Создайте аварийный диск Windows и используйте его для восстановления системы

2. **Использование Windows Recovery Environment**: Загрузитесь с загрузочной флешки Windows и используйте средства восстановления

3. **Ремонт загрузчика SystemRescue**: Используйте инструменты SystemRescue для переустановки загрузчика Windows

## Дополнительные инструкции

### Копирование всей системы

Если нужно скопировать весь раздел целиком (например для полного резервирования):
```bash
dd if=/dev/sda1 of=/mnt/usb-backup/windows-partition.img bs=4M status=progress
```

### Работа с BitLocker-зашифрованными томами

Если ваш Windows раздел зашифрован с помощью BitLocker, вам понадобится ключ шифрования. Откройте командную строку и введите:
```bash
manage-bde -status
```

Ключ шифрования обычно находится на вашем USB-накопителе или в Microsoft帐户.

## Заключение

Теперь вы знаете как создать резервную копию данных с неработающей Windows-системы. Помните что регулярные резервные копии — лучшая защита от потери данных.
