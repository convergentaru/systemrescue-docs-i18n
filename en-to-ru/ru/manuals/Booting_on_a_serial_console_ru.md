## Обзор последовательных консолей

Последовательные (serial) консоли — это альтернативный способ взаимодействия с системой, особенно полезный для серверов и嵌入式 систем. SystemRescue поддерживает загрузку и работу через последовательные порты.

## Типы последовательных соединений

### RS-232

Стандартный последовательный интерфейс для подключения:
* Консольных кабелей к ПК
* Терминалов (например Putty Serial)
* USB-адаптеров последовательных портов

### RJ-45 через UART

Некоторые материнские платы используют стандартные Ethernet-порты для последовательной связи:
* Intel Gigabit Ethernet с поддержкой serial-over-LAN
* Специальные серверные чипсеты (ASUS, Supermicro)

## Настройка оборудования

### Подключение кабеля

Для подключения к последовательному порту:
1. Используйте консольный кабель null-modem или прямое подключение
2. Подключите другой конец к ПК через USB-адаптер последовательного порта
3. Убедитесь что скорость и настройки совпадают

### Параметры соединения

Типичные параметры для SystemRescue:
* **Базовая скорость**: 115200 bps (может быть 9600, 19200, 57600)
* **Паритет**: Нет
* **Стоп-биты**: 1
* **Биты данных**: 8

### Пример настройки Putty Serial

1. Откройте PuTTY
2. Выберите "Serial" в качестве типа соединения
3. Укажите порт (например `/dev/ttyUSB0` или `COM3`)
4. Настройте скорость (обычно 115200)
5. Нажмите "Open"

## Загрузка через последовательную консоль

### Определение устройства

Сначала определите устройство вашего последовательного порта:
```bash
ls /dev/ttyS*
ls /dev/ttyUSB*
dmesg | grep tty
```

Типичные устройства:
* `/dev/ttyS0` — встроенный последовательный порт (LPT16550)
* `/dev/ttyS1` — дополнительный встроенный порт
* `/dev/ttyUSB0` — USB-адаптер последовательного порта
* `/dev/ttyACM0` — ACМ-устройство (Arduino, GPS-модули)

### Командная строка загрузки

Используйте параметр `serial` в командной строке GRUB:
```
linux /boot/vmlinuz root=/dev/sda1 console=ttyS0,115200n8
```

Или для нескольких терминалов:
```
console=tty0,ttyS0,115200n8
```

### GRUB конфигурация

Для настройки в `/etc/default/grub`:
```bash
GRUB_CMDLINE_LINUX="console=tty0,ttyS0,115200n8"
```

Обновите GRUB:
```bash
grub-mkconfig -o /boot/grub/grub.cfg
```

## Запуск SystemRescue через autoterminal

### Конфигурация autoterminal для последовательного порта

Используйте параметр `serial:` в имени терминала autoterminal:
```yaml
---
autoterminal:
    "serial:ttyS0": "/bin/bash"
    "serial:ttyS1": "/usr/bin/journalctl -f"
```

Это заменит стандартный getty на последовательных портах.

### Запуск с командной строки загрузки

Можно также запустить autoterminal через параметры загрузки:
```
autoterminal=serial:ttyS0=/bin/bash,serial:ttyS1=/usr/bin/journalctl -f
```

## Настройка последовательного порта в системе

### Проверка настроек устройства

Проверьте текущие настройки последовательного порта:
```bash
cat /proc/tty/driver/serial
```

### Изменение параметров с помощью stty

Измените параметры последовательного порта:
```bash
stty -F /dev/ttyS0 115200 cs8 -cstopb -parenb
```

### Настройка через systemd

Создайте unit-файл для автоматического запуска на последовательном порту:

```ini
[Unit]
Description=Serial console wrapper
After=systemd-logind.service

[Service]
Type=simple
ExecStart=/bin/bash -l
StandardInput=tty
StandardOutput=tty
TTYPath=/dev/ttyS0
TTYReset=true
TTYHangup=true

[Install]
WantedBy=multi-user.target
```

## Отладка проблем с последовательной консолью

### Проверка драйверов

Убедитесь что драйверы последовательных портов загружены:
```bash
modprobe 8250_pnp
modprobe serial
```

### Проверка доступа к устройству

Проверьте права доступа к устройству:
```bash
ls -l /dev/ttyS*
```

Если нет доступа, добавьте пользователя в группу `dialout`:
```bash
usermod -aG dialout $USER
```

### Проверка UART на материнской плате

Для проверки поддержки последовательного порта на материнской плате:
```bash
lspci | grep -i serial
lspci | grep -i uart
```

## Использование с виртуализацией

### QEMU/KVM

Запуск SystemRescue в QEMU с последовательной консолью:
```bash
qemu-system-x86_64 \
  -m 512 \
  -drive file=sysrescue.iso,format=iso \
  -serial mon:stdio \
  -nographic
```

### KVM с serial-over-VNC

Использование VNC для доступа к последовательной консоли:
```bash
qemu-system-x86_64 \
  -m 512 \
  -drive file=sysrescue.iso,format=iso \
  -serial stdio:port=/dev/pts/0 \
  -nographic
```

## Безопасность последовательных портов

### Ограничение доступа через udev

Создайте файл правил для ограничения доступа к последовательным портам:

```
# /etc/udev/rules.d/99-serial-console.rules
SUBSYSTEM=="tty", KERNEL=="ttyS0", MODE="0660", GROUP="console"
SUBSYSTEM=="tty", KERNEL=="ttyS1", MODE="0660", GROUP="console"
```

### Отключение неиспользуемых портов

Отключите неиспользуемые последовательные порты для безопасности:
```bash
# В /etc/modprobe.d/serial.conf
blacklist 8250_pnp
```

## Заключение

Последовательные консоли — важный инструмент для администрирования серверов и отладки систем. SystemRescue предоставляет полную поддержку последовательных портов через стандартные Linux-инструменты и опции загрузки. Используйте autoterminal для автоматического запуска оболочек на последовательных консолях.
