## Обзор autoterminal

Linux предоставляет несколько виртуальных терминалов в консоли, которые можно переключать через ALT+F\<n\>. По умолчанию создаётся 6 виртуальных терминалов (ALT+F1 до ALT+F6) и используются для getty с автоматическим входом root. См. опцию загрузки `noautologin` [Booting_SystemRescue/](/manual/Booting_SystemRescue/) и опцию `NAutoVTs` в `/etc/systemd/logind.conf`, если хотите изменить эти значения по умолчанию.

Autoterminal позволяет заменить getty и оболочку на виртуальном терминале программой вашего выбора.

## Конфигурация

Конфигурация делается исключительно через записи в [YAML-конфигурации](/manual/Configuring_SystemRescue/) используя область `autoterminal`. Имя устройства терминала (`tty<n>`) — это ключ, значение — команда для выполнения:

```
---
autoterminal:
    tty2: "/usr/bin/setkmap"
    tty3: "/root/myscript \"parameter one\""
    tty4: "/usr/bin/tmux"
    tty8: "/usr/bin/journalctl -f"
```

Если хотите использовать параметры команды, включающие пробелы или кавычки, нужно экранировать их обратным слэшем ("\\"). Команда, заданная, записывается в systemd unit-файл без изменений, поэтому смотрите документацию systemd для деталей.

## Порядок выполнения

Autoterminals запускаются только после завершения [autorun](/manual/Run_your_own_scripts_with_autorun/). Это позволяет использовать autorun для подготовки данных или загрузки программ, используемых для autoterminal, с удалённого сервера.

Systemd по умолчанию задерживает запуск getty на 5 секунд (`Type=idle`). Это предотвращает любой консольный вывод других программ от засорения терминала. Autoterminal всегда сразу запускает запрограммированные программы вместо этого (`Type=simple`). Это для прямого разрешения взаимодействия с пользователем без времени ожидания.

## Возможные конфликты

По умолчанию systemd создаёт 6 виртуальных терминалов. Но Linux позволяет до 63 виртуальных терминалов, хотя обычные клавиатуры не имеют более 12 F-клавиш для доступа к ним. Можно использовать все виртуальные терминалы, которые можно достать с клавиатурой через autoterminal. Для каждого запрограммированного autoterminal стандартные терминалы, запрограммированные в systemd, будут скрыты для предотвращения конфликтов.

Когда используете опцию загрузки `dostartx` [Booting_SystemRescue/](/manual/Booting_SystemRescue/), нужно оставить `tty1` на его стандартной конфигурации, иначе `dostartx` не будет работать. Можно всё ещё вручную выполнить `startx` на других терминалах когда `tty1` используется autoterminal.

## Последовательные терминалы

Можно также использовать autoterminal на [serial consoles](/manual/Booting_on_a_serial_console/). Поскольку последовательные устройства требуют другую конфигурацию, autoterminal должен знать что он используется с последовательной консолью. Это делается префиксом имени терминала `serial:`:

```
---
autoterminal:
    "serial:ttyS0": "/usr/bin/tmux"
```
