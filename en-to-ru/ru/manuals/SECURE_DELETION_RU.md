# Безопасное удаление данных

## Введение

Безопасное удаление данных не так просто, как вы можете подумать. Когда вы удаляете файл используя стандартные команды операционной системы (например `rm` в UNIX или `del` в DOS или очистка корзины в WINDOWS) операционная система НЕ удаляет файл, содержимое файла остаётся на вашем жёстком диске.

Большинство операционных систем только удаляют ссылки на файл когда им говорят удалить файл. Файл — который вы думали что навсегда исчез — остаётся на диске пока не будет создан другой файл поверх него (пока другой файл не перезапишет пространство диска где всё ещё хранится «удалённый» файл), и даже после этого, возможно восстановить данные изучая магнитные поля на поверхности диска используя криминалистическое оборудование.

До того как файл будет перезаписан новым файлом любой может легко извлечь данные например используя утилиту undelete диска. И даже после этого некоторые люди (например трёхбуквенные агентства) с особым оборудованием способны восстановить ваши данные по крайней мере частично.

У каждого есть конфиденциальные данные которые он хочет хранить в частном порядке. Например финансовые данные, личные email, следы вашего серфинга в интернете и т.д. Я слышал случаи где люди продавали свои старые компьютеры или жёсткие диски и покупатель восстанавливал их финансовые бизнес данные.

Единственный способ сделать восстановление ваших конфиденциальных данных почти невозможным — это перезаписать («wipe» или «shred») данные несколькими определёнными паттернами.

**ВНИМАНИЕ:** Использование утилит wipe или shred основано на очень важном предположении: что файловая система перезаписывает данные на месте. Это традиционный способ делать вещи, но многие современные файловые системы не удовлетворяют этому предположению например Ext4, XFS, ReiserFS и т.д.

Смотрите [http://www.die.net/doc/linux/man/man1/shred.1.html](http://www.die.net/doc/linux/man/man1/shred.1.html) для больше информации. В таком случае решением может быть wipe/shred всего устройства (раздела) где хранились конфиденциальные данные чтобы убедиться что данные действительно перезаписаны.

SystemRescue предоставляет несколько утилит которые способны сделать восстановление данных почти невозможным — я говорю почти невозможно, потому что никто не может гарантировать что например NSA или FBI не могли бы восстановить по крайней мере часть этих данных. но используя эти инструменты это становится сложнее.

**ВНИМАНИЕ:** С другой стороны вы не сможете восстановить любые данные, удалённые этими инструментами. Будьте осторожны. Мы не будем брать ответственность за потерю данных.

Если вы хотите иметь абсолютную безопасность используйте шифрование например LOOP-AES [http://loop-aes.sourceforge.net/](http://loop-aes.sourceforge.net/)
Зашифруйте ваш домашний директорию или создайте зашифрованный раздел или контейнер чтобы сохранять данные там.

## Основные инструменты

- **SHRED** из GNU coreutils смотрите [https://www.gnu.org/software/coreutils/coreutils.html](https://www.gnu.org/software/coreutils/coreutils/) может использовать shred для безопасного удаления простых файлов но также целых разделов или жёстких дисков. Shred по умолчанию использует 25 перезаписывающих проходов, вы можете увеличить и уменьшить количество перезаписывающих проходов. Поэтому shred быстрее чем wipe (см. ниже).

Например безопасно удаляя все данные на первом IDE жёстком диске:

```
shred -v /dev/hda
```

- **WIPE** из Sourceforge смотрите [http://wipe.sourceforge.net](http://wipe.sourceforge.net) Похож shred вы можете использовать wipe для безопасного удаления простых файлов но также целых разделов или жёстких дисков. Wipe по умолчанию использует 35 перезаписывающих проходов. Wipe медленнее чем shred, потому что использует по умолчанию больше перезаписывающих проходов и поэтому более безопасен.

Например безопасно удаляя Windows 98 Swap File с смонтированного (FAT) windows раздела используя 35 перезаписывающих проходов:

```
wipe -D  /mnt/windows/win386.swp
```

## Другие инструменты

Есть другие инструменты на SystemRescue которые вы можете использовать подобным образом для перезаписи особенно устройств например

- **nwipe:** выбирать диски для wipe в текстовом UI; несколько алгоритмов для выбора; форк Darik's Boot and Nuke (DBAN)
- **dd:** if=/dev/zero или /dev/urandom, of=device
- **dd_rescue:** работает подобно «dd»
- **badblocks:** с -w опцией для записей 4 статических прохода

Для больше информации посмотрите на мануалы.

## Тестирование

Чтобы увидеть как работают инструменты и проверить если все секторы например флешки были перезаписаны, вы можете использовать VCHE, виртуальный консольный hex редактор. В нашем примере мы безопасно сотрём все данные с флешки.

Сначала наберите следующую команду:

```
shred -v -n 1 /dev/fd0
```

Shred перезапишет флешку одним случайным проходом.

Затем давайте запустим:

```
vche-raw /dev/fd0
```

Флешка должна быть заполнена случайными значениями.

Затем мы набираем следующую команду:

```
shred -v -n 1 -z /dev/fd0
```

Опция -z сделает дополнительный проход с нулевыми значениями.

И мы запускаем VCHE снова

```
vche-raw /dev/fd0
```

Флешка должна быть заполнена нулевыми значениями.
